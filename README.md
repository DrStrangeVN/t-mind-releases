# T-Mind Releases & Community Template Packs

Kho phân phối công khai cho ứng dụng **T-Mind** (macOS 14+):
- **Releases**: Bộ cài đặt `.dmg` và mã kiểm tra `SHA256SUMS.txt` dùng cho cơ chế cập nhật tự động trong ứng dụng.
- **remote-templates.json & templates/**: Danh mục gói mẫu cộng đồng tải trực tiếp từ **Kho mẫu trực tuyến (Template Packs)**.

## Xác thực SHA-256

```bash
shasum -a 256 -c SHA256SUMS.txt
```
